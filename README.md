# AutoDropshipPrime Marketing Website

Production-oriented Next.js App Router frontend based on the supplied AutoDropshipPrime brief and brand logo.

## Stack
- Next.js + React + TypeScript
- Tailwind CSS
- Ant Design
- Material UI (selective use)
- Framer Motion
- Lucide React
- Recharts

## Start
```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Important implementation notes
- Pricing and plan limits are intentionally configurable placeholders because final commercial values were not supplied.
- eBay and Google Sheets are the only connections surfaced as confirmed/current-focus items in marketing copy.
- Dashboard values, tables and charts are explicitly demo data.
- Form submissions are frontend demo handlers until a production backend is connected.
- Replace `https://autodropshipprime.example` in metadata, robots and sitemap with the final production domain.
